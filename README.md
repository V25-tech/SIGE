# 📚⚙️ SIGE

## Sistema Integrado de Gestão Escolar

O **SIGE** é uma aplicação web desenvolvida em **Django** para apoiar a gestão escolar administrativa e pedagógica.

O projeto foi desenvolvido para a **EMEB Dionysio Bovo**, buscando centralizar informações acadêmicas, administrativas e pedagógicas em uma única plataforma.

---

# 🎯 Objetivo

Fornecer uma plataforma integrada que auxilie a gestão escolar, automatize processos administrativos e contribua para o acompanhamento pedagógico dos alunos.

---
